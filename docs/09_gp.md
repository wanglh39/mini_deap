## 一、背景：GP 和 GA 有什么不同？

前 8 阶段的个体都是**定长向量**（位串/浮点数组/排列）。遗传规划（GP）的个体是**变长语法树**：

```
    mul
   /   \
  x    add
      /   \
     y     1
```
表示 `mul(x, add(y, 1))`。

**GP 的应用场景**：符号回归（自动发现数学公式）、程序合成、控制器设计。个体是"程序"，fitness 是程序在任务上的表现。

**核心差异**：
| | GA（前8阶段） | GP（本阶段） |
|---|---|---|
| 个体 | 定长向量 | 变长树 |
| 交叉 | 位/段交换 | 子树交换 |
| 变异 | 位翻转/高斯扰动 | 子树替换 |
| 表示 | list/array | 扁平列表（深度优先序） |

## 二、核心设计思想

### ① 扁平列表表示树 —— 深度优先序

树 `mul(x, add(y, 1))` 存为扁平列表：
```python
[Primitive("mul"), Terminal("x"), Primitive("add"), Terminal("y"), Terminal(1)]
```

**为什么用扁平列表而非嵌套结构？** 嵌套 `["mul", "x", ["add", "y", 1]]` 虽然直观，但：
- 切片操作难（子树是嵌套的，不是连续切片）
- deepcopy 慢（嵌套递归）
- 内存开销大（每层一个 list）

扁平列表让子树是**连续切片**，交叉/变异用 slice 操作，O(1) 切换子树。

### ② searchSubtree —— 用 arity 累积找子树范围

```python
def searchSubtree(self, begin):
    end = begin + 1
    total = self[begin].arity        # 根节参数数
    while total > 0:
        total += self[end].arity - 1 # 每加一个节点：消耗1槽位，提供arity个
        end += 1
    return slice(begin, end)
```

**算法**：子树 = 根节点 + 所有参数子树。`total` 是"还缺多少个参数"。
- 初始 `total = arity`（根节点需要 arity 个参数）
- 每加一个节点：消耗 1 个槽位（`-1`），提供 `arity` 个新槽位
- `total == 0` 时子树闭合

**例子**：`[mul, x, add, y, 1]`，searchSubtree(2)：
- begin=2, total=add.arity=2, end=3
- 加 y：total=2+0-1=1, end=4
- 加 1：total=1+0-1=0, end=5 → slice(2,5) = [add, y, 1] ✓

### ③ compile —— eval 编译树为函数

```python
def compile(expr, pset):
    code = str(expr)                          # "mul(ARG0, add(ARG0, 1.0))"
    code = "lambda {args}: {code}".format(...)  # "lambda ARG0: mul(ARG0, add(ARG0, 1.0))"
    return eval(code, pset.context, {})       # 在 pset.context 里查 add/mul
```

**机制**：
1. `str(tree)` 递归格式化为 Python 表达式（PrimitiveTree.__str__）
2. 包成 `lambda ARG0: ...`
3. `eval` 在 `pset.context` 里查函数名（add→operator.add, mul→operator.mul）

**为什么用 eval 而非递归解释？** eval 编译成 Python 字节码，调用快。递归解释每次遍历树，慢 10-100 倍。GP 评估次数巨大（pop×ngen×采样点），速度关键。

### ④ 子树交叉 —— cxOnePoint

```python
def cxOnePoint(ind1, ind2):
    index1 = random.randint(1, len(ind1) - 1)   # 随机选非根节点
    index2 = random.randint(1, len(ind2) - 1)
    slice1 = ind1.searchSubtree(index1)          # 找子树范围
    slice2 = ind2.searchSubtree(index2)
    ind1[slice1], ind2[slice2] = ind2[slice2], ind1[slice1]  # 交换子树
```

**流程**：各随机选一个非根节点 → searchSubtree 找子树切片 → 交换两个切片。

**为什么选非根节点？** 交换根节点等于整个树交换，无意义。排除 index=0 保证只交换子树。

### ⑤ 子树变异 —— mutUniform

```python
def mutUniform(individual, expr, pset):
    index = random.randrange(len(individual))   # 随机选一个节点
    slice_ = individual.searchSubtree(index)    # 找子树范围
    individual[slice_] = expr(pset=pset)        # 用新生成的子树替换
```

**流程**：随机选一个节点 → searchSubtree 找子树 → 用 `expr` 生成的新子树替换。

`expr` 通常是 `genHalfAndHalf`（生成随机树）。变异后子树是全新的随机树。

## 三、逐类精读

### 3.1 Primitive / Terminal —— 树节点

```python
class Primitive:
    __slots__ = ('name', 'arity', 'args', 'ret', 'seq')
    def format(self, *args):
        return self.seq.format(*args)   # "mul({0}, {1})".format(x, y) → "mul(x, y)"

class Terminal:
    __slots__ = ('name', 'value', 'ret', 'conv_fct')
    @property
    def arity(self): return 0           # 终端 arity 恒 0
```

**Primitive** 是函数节点（add/mul/sub），有 arity（参数数）。**Terminal** 是终端节点（变量/常量），arity=0。

`__slots__` 省内存（GP 种群大，节点多）。`format` 生成调用代码——`Primitive("mul").format(x, y)` → `"mul(x, y)"`。

### 3.2 PrimitiveSet —— 函数集 + 终端集

```python
pset = PrimitiveSet("MAIN", 1)              # 1 个变量 ARG0
pset.addPrimitive(operator.add, 2, name="add")
pset.addTerminal(1.0, name="one")
```

`PrimitiveSet("MAIN", 1)` 自动添加 1 个输入变量 ARG0。`addPrimitive` 注册函数到 `primitives` 列表 + `context` 字典（eval 用）。`addTerminal` 注册常量/变量到 `terminals` 列表。

`context = {"__builtins__": None}` 是 eval 的命名空间——`add`/`mul` 等函数名映射到实际函数。`__builtins__=None` 防止恶意代码注入。

### 3.3 PrimitiveTree —— 树个体

```python
class PrimitiveTree(list):
    def __str__(self):        # 递归格式化为代码
    def height(self):         # 树高
    def searchSubtree(self, begin):  # 子树切片
    def __deepcopy__(self, memo):    # 深拷贝
```

继承 `list`，树是扁平列表。`__str__` 用栈递归组装代码——遍历节点，栈中每个元素是 `(node, args)`，当 args 收满 node.arity 个时弹出并 format。

`__deepcopy__` 自定义：先浅拷贝列表，再深拷贝 __dict__（fitness 等）。比默认 deepcopy 快（列表元素是 Primitive/Terminal，不可变，浅拷贝安全）。

### 3.4 树生成 —— genFull / genGrow / genHalfAndHalf

```python
def generate(pset, min_, max_, condition, type_):
    height = random.randint(min_, max_)    # 随机树高
    stack = [(0, type_)]
    while stack:
        depth, type_ = stack.pop()
        if condition(height, depth):       # 停止 → 放终端
            expr.append(random.choice(pset.terminals[type_]))
        else:                              # 继续 → 放函数
            prim = random.choice(pset.primitives[type_])
            expr.append(prim)
            for arg in reversed(prim.args):
                stack.append((depth + 1, arg))  # 参数入栈
```

**三种策略**：
- **genFull**：`condition = depth == height`，所有叶在同一深度（满树）
- **genGrow**：`condition = depth == height or random < terminalRatio`，叶可不同深度
- **genHalfAndHalf**：一半满树一半生长树

**为什么用栈而非递归？** 栈模拟递归，避免 Python 递归深度限制（树可能很深）。

## 四、符号回归实战

### 4.1 问题定义

用 GP 拟合 f(x) = x² + x + 1。个体是语法树，fitness = 预测值与目标值的 MSE。

### 4.2 代码结构

```python
pset = PrimitiveSet("MAIN", 1)               # 变量 ARG0
pset.addPrimitive(operator.add, 2, name="add")
pset.addPrimitive(operator.sub, 2, name="sub")
pset.addPrimitive(operator.mul, 2, name="mul")
for c in [-2.0, -1.0, 0.0, 1.0, 2.0]:
    pset.addTerminal(c)

tb.register("expr", gp.genHalfAndHalf, pset=pset, min_=1, max_=2)
tb.register("individual", gp.PrimitiveTree, tb.expr)
tb.register("mate", gp.cxOnePoint)
tb.register("mutate", gp.mutUniform, expr=tb.expr_mut, pset=pset)
tb.register("evaluate", eval_symbreg, pset=pset)   # compile + MSE
```

### 4.3 运行结果

```
gen  avg     min
0    6.33    0.24
...
40   1.81    0.24

最优公式: sub(sub(add(-2.0, ARG0), add(-1.0, 0.0)), -2.0)
MSE = 0.241267
```

**分析**：GP 找到的公式简化后是 `x - 1`，MSE=0.24。目标是 `x² + x + 1`，GP 没找到精确解。原因：
1. **常量集有限**（只有 -2..2 整数），无法表达任意系数
2. **树深限制**（max_=2），无法生成深树
3. **ngen 不够**（GP 收敛慢）

增加 ngen、放宽树深、加 Ephemeral 常量可改善。教学版展示流程为主。

## 六、常见陷阱

1. **creator.create 类名冲突**：多测试文件都用 `creator.create("Ind", ...)` 但基类不同，后加载的覆盖。解决：每文件用独立类名（如 IndGP）。
2. **树膨胀（bloat）**：GP 树会无限制长大（交叉/变异加节点），评估变慢。需限制树深（max_）或用 parsimony pressure（惩罚大树）。
3. **compile 的 eval 安全**：`context = {"__builtins__": None}` 防注入。但仍非安全沙箱，勿 eval 不可信树。
4. **除零错误**：GP 树可能产生 `div(x, 0)`。用保护除法 `div(a, b) = a/b if |b|>0.001 else 1`。
5. **searchSubtree 的 arity 累积**：若树不合法（某节点 arity 与实际参数数不匹配），searchSubtree 会越界。PrimitiveTree.__setitem__ 检查合法性。
6. **genFull 的 min_==0**：若 min_=0 且无终端，会 IndexError。保证终端集非空。

## 七、Python 语言特性备忘

- **`__slots__`**：固定属性集，省内存（每实例省一个 __dict__）。GP 节点多，省内存显著。代价：不能动态加属性。
- **`eval(code, context, {})`**：在 context 命名空间里执行 code。`{"__builtins__": None}` 禁用内置函数（防注入）。
- **`slice(begin, end)`**：切片对象，`list[slice]` 等价 `list[begin:end]`。searchSubtree 返回 slice 供 `ind1[slice1] = ind2[slice2]` 用。
- **栈模拟递归**：`stack = [(0, type_)]` + `stack.pop()` + `stack.append()`。避免 Python 递归深度限制（默认 1000）。
- **`reversed(prim.args)`**：参数逆序入栈（栈是 LIFO），保证深度优先序正确。

## 八、关键收获

1. **树用扁平列表表示（深度优先序）**：子树是连续切片，交叉/变异用 slice 操作 O(1)。比嵌套结构高效。
2. **searchSubtree 用 arity 累积**：`total += arity - 1`，total==0 时子树闭合。巧妙的线性扫描找子树范围。
3. **compile 用 eval 编译**：树 → 代码字符串 → lambda → Python 字节码。比递归解释快 10-100 倍。
4. **子树交叉/变异**：随机选节点 → searchSubtree → 切换/替换子树。在子树层面操作，保持语法合法性。
5. **GP 收敛慢且易树膨胀**：需限制树深 + 足够 ngen + 丰富常量集。教学版展示流程为主。
6. **creator 类名冲突**：多文件 create 同名类会覆盖。每文件用独立类名。
